# student-grade-management-kourtneystewart

## Description
This project is a Java program that manages student grades using 1D arrays. It allows users to add students, display records, search for grades, calculate averages, and find the highest and lowest grades

## Features 
- Add student and grade
- Display all students
- Search student grade
- Calculate class average
- Find highest and lowest grades

## How to Run
1. Compile: javac StudentGradeManagementSystem.java
2. Run: java StudentGradeManagementSystem
